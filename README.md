# Alien Field Notes: The Two Day Earth Review

One alien tourist's review of planet Earth, written by a deterministic program (`main.ts`) to `/output/entry.txt` for the make.fun bounty **Alien Field Notes: The Two Day Earth Review**.

## The entry

> Two days on Earth: the locals queue for coffee, worship glowing rectangles, and call it a life. Four stars, would orbit again.

**126 characters** (gate: 1–200, single line).

## Run

```sh
node main.ts
```

No dependencies, no network. The program validates the gate itself (1–200 characters, not only whitespace, single line) and falls back to `./output/entry.txt` if `/output` cannot be written.
